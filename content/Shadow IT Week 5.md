 
## What did I do?
I looked up the topic shortly before the presentation - the issue that it addresses, the spotty coverage of software in companies is something i can emphasize with. In my current job very basic software has to be requested through management. Up until seeing this presentation i could not figure out, what bigger purpose this achieved, aside from possibile legal issues when using private software.
## What did I learn?
I was surprised to learn how many companies struggle with the issue. I did not think that it was this big of an issue beforehand.

Also i can better understand why my company is so strict with software requests, to mitigate risks, the exposure of the company needs to be known. If everyone uses different software supply chain attacks and blind spots make data security risky.

As with other security issues, the key seems to be to make the process of new software approval more transparent and easy. If it is really difficult to get a decision for a certain piece of software either the job remains inefficient, or the rules are circumvented in favor of shadow IT.
